# Проверки 0.2.0 alpha — 2026-10-03

Цель: Forge 47.4.13 / Java 17 / Minecraft 1.20.1, Better MC BMC4 v55.5.

## Выполнено

- Gradle build, reobfJar и упаковка нового JAR: успешно.
- verifyModels: деревья трех моделей строятся; все девять активностей каждого персонажа дают конечные координаты и вращения. Кольцо является дочерней частью руки.
- Forge GameTestServer: **все 7 обязательных тестов прошли**.
  1. Вылупление Сюси при восстановлении воды; пауза и сохранение прогресса без нее.
  2. NBT владельца, доверия, режима и стадии; защита от смертельного обычного урона.
  3. Ожидание своей Сюси, игнорирование чужой, приоритет команды «жди».
  4. Расход ровно одного яблока за действие, задержка подбора, удаление последнего предмета; Маруся яблоко не расходует.
  5. Тревога Маруси при монстре без назначения цели атаки и повреждения монстра.
  6. Кормление владельцем, cooldown и отказ чужому игроку; выдача достижений за последнее печенье в стеке, сбор своей семьи и взрослую Дюдюньку.
  7. Реальные тики AI: достижение за ожидание еще не выдано на 100-м тике, выдано к 150-му (порог ожидания 120 тиков / 6 секунд).
- Сервер загрузил все новые ресурсы достижений. Основные поля NBT не переименованы; данные 0.1.0 остаются совместимыми.
- Итог: **BUILD SUCCESSFUL** для build verifyModels runGameTestServer -x downloadAssets.

Промежуточная проверка достижений использовала Forge FakePlayer, которому Forge запрещает award. Итоговый тест использует обычного ServerPlayer с отключенной сетью. Штатный mock-login GameTest также требует настоящий сетевой канал в Forge; тест регистрирует игрока напрямую в уровне. Производственная логика не содержит обхода запрета FakePlayer.

## Не выполнено

- Графический клиент: визуальная приемка анимаций, отдыха на мебели и навигации; дисплея в среде нет.
- Полный запуск 393 модов Better MC v55.5, шейдеры Oculus и resource packs.
- Сетевой сеанс с двумя реальными клиентами и авторизацией.
- Производительность большой компании, все виды рельефа, мебель других модов.
- Полная матрица погоды, сна, переходов между измерениями и потери дома.

Проверки моделей подтверждают структуру и корректность чисел, не художественное качество. Ночная мебель, укрытие и интерес к растениям реализованы, но требуют игровой приемки по TESTING.md. Предыдущие проверки сохранены в VALIDATION-0.1.0.md.
