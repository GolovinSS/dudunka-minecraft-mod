# Проверки 0.15.0 alpha — 2026-10-04

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- Итоговые build/reobfJar, verifyModels и Forge GameTestServer; все 50 обязательных тестов (45 прежних + 5 путешествия).
- Счетчик требует шесть полных последовательных секунд; первый отсчет, пропуск времени, движение и прерывание задачи не дают пропущенный stall. Пауза 20 секунд сохраняется при остановке/повторном запуске goal.
- Реальный выбор безопасного загруженного места, отказ для занятой позиции, выбор другой свободной, сохранение UUID/всех additional NBT полей после перемещения и сброс накопленного падения.
- Чужой хозяин, «ждать», активность ожидания Сюси, воздушный хозяин и пассажир лодки отвергаются; магма, ягодный куст и жидкость над позицией не подходят. Отключение конфигурацией проверено.
- FamilyFollowGoal действительно срабатывает на загруженных серверных ticks через недостижимый промежуток: до шести секунд перемещения нет, после персонаж рядом. Это прямой запуск goal, персонаж с NoAI для изоляции других занятий.
- Отдельный batch с настоящими AI/GoalSelector/навигацией: Сюся проходит открытый путь с нормальной скоростью и не телепортируется. Проверяется фактическое продвижение и сохранение отставания.
- Все девять моделей и 12 активностей проверены verifyModels; модели/PNG текстур персонажей не изменены.

## Ограничения

- Полный BMC4 v55.5, графическая приемка, реальный сетевой сеанс/выделенный сервер, длинное путешествие и опасные блоки каждого стороннего мода не запускались.
- Счетчик перерывов проверен последовательностью наблюдений; реальная выгрузка/загрузка в процессе догоняния и дисковый перезапуск пользовательского мира не проверялись.
- Догоняние ограничено загруженной семьей в одном измерении, до 64 блоков. Межмирового автоматического переноса и восстановления выгруженных/потерянных сущностей нет.

Сохраняемые поля персонажей/дружбы/переноски сохранены. Счетчик/пауза временные, без новых NBT полей и библиотек. Предыдущий отчет: VALIDATION-0.14.0.md. Правила: FAMILY-TRAVEL.md; ручная приемка: TESTING.md.
