# Проверки 0.7.0 alpha — 2026-10-04

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- Gradle `build verifyModels runGameTestServer -x downloadAssets --offline`: BUILD SUCCESSFUL; reobfJar выполнен.
- Все 25 обязательных Forge GameTest прошли: 22 прежних и 3 новых.
- Два собственных персонажа получают общую сцену и разные безопасные места. Чужой персонаж исключается; путь к каждому месту достижим и не проходит через зажженный костер.
- Goal запускает подход; после перемещения персонажа тестовой фикстурой в зарезервированное место включается CAMP_REST без постоянной команды «жди». Вставание хозяина отменяет сцену, повторные tick после отмены безопасны, навигация остановлена.
- Повторное приседание после сброса дает новую сцену; синий костер поддерживается, его гашение отменяет отдых.
- Один свой плюс чужой персонаж не образуют сцену. Команда «жди» исключает участника и прекращает сцену из одного персонажа; возврат участника разрешает перепланирование. Уход хозяина прекращает отдых.
- Ожидание собственной отставшей Сюси имеет приоритет; после удаления Сюси обычное любопытство уступает отдыху.
- verifyModels проверяет все 12 активностей для трех моделей, включая конечные координаты/углы позы CAMP_REST.

## Не выполнено

- Полный BMC4 v55.5, графическая приемка поз и естественный пеший подход в длительной игре. Тест прибытия использует перемещение фикстурой; реальная навигация по сложному рельефу требует ручной приемки.
- Сетевая игра с несколькими реальными клиентами, перезапуск/выгрузка мира и взаимодействие с защитой территорий других модов.
- Природная частота яиц из 0.6.0 остается непроверенной в полном модпаке.
- Числовая дружба между персонажами и самостоятельные домашние семейные сцены остаются открытыми.

Сцены хранят только временные UUID/координаты с отдельными резервированиями по миру/владельцу. Новых зависимостей и изменений NBT персонажей нет. Предыдущий отчет: VALIDATION-0.6.0.md. Ручная приемка: TESTING.md.
