# Яйца в Better MC BMC4 v55.5 — 0.18.0 alpha

Версии взяты из manifest официального архива сборки (CurseForge file 7443284). Проверены JAR MVS 5.0.3 (file 7311820), YUNG’s Better Dungeons 1.20-Forge-4.0.4 (5271360), Biomes O’ Plenty 19.0.0.96 (6364065). Таблицы не придуманы: подтверждены JSON ресурсов и назначениями в NBT структур; SHA256 и примеры путей — BMC-EGG-SOURCES.json. Сторонние JAR/ресурсы не включены в наш мод.

Шанс — один дополнительный бросок нашего модификатора при формировании указанной добычи, умноженный на eggLootMultiplier (0 отключает, максимум результирующего шанса 100%). Не каждый сундук структуры использует одну таблицу. Прежние ванильные находки сохранены: жилые деревенские дома для Дюдюньки; шахты/лесной особняк для Маруси; обычное подземелье для Сюси.

Перед добавлением проверяется уже присутствующее яйцо данного вида; наш модификатор не добавляет еще одно такое же. Он не удаляет существующие предметы или дубли, сформированные другими модами. В BMC4 есть Loot Integrations и его дополнения, поэтому итоговая вероятность/число предметов могут отличаться от одного нашего броска и требуют измерения в игре.

Repurposed Structures 7.1.19 (6797349) в архиве имеет importModdedItems=true и пустой blacklist в config/repurposed_structures-forge/modded_loot.toml. Дополнительных прямых модификаторов на RS не добавлено, чтобы не наслаивать их на существующий импорт из ванильных таблиц. Реальное распространение наших яиц через этот импорт не заявляется как проверенное полным игровым запуском.

## Природные яйца

К существующим болотам/мангровым болотам/lush caves добавлены необязательные BOP Bayou, Marsh, Wetland. ID подтверждены biome JSON и тегом forge:is_swamp самого BOP. В нашем теге значения required=false: без BOP мод продолжает работать. Сохраняются прежние частота, поиск свободного места на траве/мху у воды, отсутствие лавы/близкого яйца, обычные условия вылупления. Грязь/песок не добавлены как основания; пригодных мест может быть мало, появление не гарантируется.

## Существующие сохранения

Новый мир не требуется. Еще не сформированный контейнер со ссылкой на поддержанную таблицу использует текущие модификаторы при создании добычи. У обычных сундуков это обычно первое открытие; другой мод или воронка может сформировать содержимое раньше. Если добыча уже записана в Items, она не пересоздается при установке/обновлении или повторном открытии.

Природные яйца появляются при генерации новых чанков; готовые чанки/постройки не переписываются. Здесь нет ретрогенерации и нет автоматического пополнения старых сундуков. Контейнеры с отдельной добычей на игрока/предварительно сформированным содержимым требуют отдельной игровой проверки.

## Путеводитель

При первом входе после обновления выдается один существующий семейный альбом с вкладками «Поиск яиц» / «Моя семья». Шесть страниц описывают доступные места, старые миры и заботу. Данные о наличии сторонних модов/отключении источников берутся с сервера, а не по модам клиента. Повторная выдача, полный инвентарь и потеря описаны в FAMILY-ALBUM.md. Будущие подсказки секрета смогут обновлять страницы уже выданных альбомов без нового предмета.

## Приемка

Проверены идентификаторы точных исходных ресурсов, регистрация/фильтрация GLM, сохраненный еще не сформированный ванильный сундук и отсутствие повторного наполнения. Полный BMC4, генерация реальных новых BOP чанков, моды индивидуальной добычи и графический экран не запускались; см. VALIDATION.md / TESTING.md.
