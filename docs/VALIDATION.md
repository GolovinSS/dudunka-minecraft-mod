# Проверка 0.24.0-alpha — 2026-10-04

## Подтверждено

- Minecraft 1.20.1 / Forge 47.4.13 / JDK 17. Полный GameTest-прогон: **124/124 обязательных теста**, exit 0 (phase24-test4.log). 112 прежних и 12 новых сценариев.
- Новые проверки: цветок расходуется ровно один раз; принятие/повторная выдача/сохранение; чужой владелец/расстояние/недостающий предмет/роза визера; пропуск без штрафа/отсутствие срока; настоящие кормление и сытость через прямое взаимодействие и альбом; готовый дом с назначенной мебелью; аутентификация сессии, удерживаемый альбом и replay; codec и ограничение поврежденного NBT.
- Проверены прерывания прогулок из-за движения владельца, команды ожидания, исчезновения цветка/участника, опасного пола, дождя и ночи. Подход не засчитывается за отдых. В live-сценарии обычный AI всех трех друзей подходит пешком к разным местам, включая Сюсю; после ухода игрока сценка освобождает движение. Цветок сохраняется.
- Прежние тесты мебели/общих встреч, дома, яиц, еды, доверия, переноски, возврата/измерений, историй и достижений включены в полный прогон.
- Полный build и verifyModels успешны: прежние девять возрастных моделей и 1620 комбинаций поз/вариантов/усиков. Изменений геометрии/PNG персонажей и ordinal активностей нет.
- Протокол альбома 8: совместные обязательные обновления сервера и клиентов. Персонажный NBT сохранен; просьбы — отдельные данные владельца/вида с сохранением при переноске/возврате. Новый предмет подарка имеет обычную бумажную иконку; рисунок/текст открываются отдельно, чтение не разблокирует исследовательские истории.
- JSON ресурсов корректен, ru/en имеют одинаковые 295 ключей; git diff --check чист. Прежняя инструкция дополнена без увеличения пяти страниц памятки.

## Исправления при проверке

- Погодный тест теперь явно устанавливает текущую интенсивность дождя: смена параметров погоды сама по себе интерполируется. Выбор времени прогулки проверяет игровое время напрямую, без задержки обновления освещенности после /time.
- Положительная площадка прогулки очищает посторонних монстров от соседних тестов. Ожидание хозяина действительно измеряется до старта; сцена не начинается сразу при появлении цветка.
- Проверка поврежденного пакета девяти записок адаптирована к хвосту новых данных просьб. Прежняя проверка кормления Сюси теперь размещает игрока рядом, как при настоящем взаимодействии.
- Дополнительная Дюдюнька, не участвующая в текущей встрече, не заменяет чужую действующую сценку той же семьи.

## Еще требуется игровая проверка

- Полный Better MC BMC4 v55.5 не запускался здесь. Визуальные анимации, GUI альбома/подарков на разных GUI Scale, настоящий обмен пакетами клиент–сервер и навигация в сложных структурах остаются ручной проверкой.
- Члены одного вида у одного владельца разделяют просьбу/воспоминания. Прогулка приглашает максимум по одному представителю вида. Альбом остается снимком: таймер и список обновляются при новом открытии/ответе сервера.
- Подарок при полном инвентаре выпадает рядом; рисунок декоративный. Обмен подарками не переносит прогресс заданий.
