# Проверки 0.1.0 alpha — 2026-10-03

## Выполнено

- Точный архив Better MC BMC4 v55.5: прочитаны manifest.json и modlist.html; Forge 47.4.13 / Minecraft 1.20.1, 393 мода.
- Компиляция Java: SUCCESSFUL на Java 17.0.20 и Forge 47.4.13; 4 предупреждения устаревшего API, без ошибок.
- Gradle `build`: задача выполнена; JAR прошел reobfJar. Дальнейшая загрузка клиентских assets в первом комбинированном запуске не удалась; серверные проверки запущены отдельно с `-x downloadAssets`, поскольку сервер не использует звуковые и графические assets.
- Проверены 27 JSON-файлов ресурсов; все ссылки списка Global Loot Modifiers ведут к существующим файлам; `replace: false`; языковые ключи ru_ru/en_us совпадают.
- Проверена упаковка JAR и подстановка версий в mods.toml; 3 egg blockstates присутствуют.
- Gradle `verifyModels`: PASS DUDUNKA (22 части), MARUSYA (14), SYUSYA (9). Деревья геометрии успешно строятся без графического окна.
- Forge GameTestServer стартовал с модом, загрузил данные и реестры без ошибок мода.
- **Все 2 обязательных GameTest прошли.**
  1. Сюся не вылупляется без воды, таймер сохраняется. После добавления воды появляется ровно один персонаж-малыш нужного типа.
  2. Владелец, доверие, ожидание и стадия восстанавливаются из NBT. Смертельный обычный урон восстанавливает здоровье и оставляет персонажа живым.
- Итог отдельного запуска `verifyModels runGameTestServer -x downloadAssets`: **BUILD SUCCESSFUL**.

## Не выполнено

- Графический клиент: нет дисплея; качество отображения, текстур и анимаций не проверено глазами.
- Полный Better MC v55.5: состав подтвержден, игровой запуск с 393 модами не выполнен.
- Многопользовательский сеанс с двумя клиентами, шейдеры Oculus, другие resource packs, тест производительности.
- Реальное выпадение яиц в игровых сундуках; взаимодействие с модовыми структурами/персонализированным лутом.
- Полная матрица опасностей и переходы между измерениями.

В логе dev-сервера были сетевые ошибки обращения к сервисам Mojang и предупреждения первой генерации конфигов. Они не помешали выполнению двух GameTest; это не проверка авторизованного сетевого сеанса.

Результаты показывают работоспособность проверенных частей альфы в Forge dev-сервере. Они не означают подтвержденную совместимость с полной сборкой Better MC. Ручная приемка — в TESTING.md.
