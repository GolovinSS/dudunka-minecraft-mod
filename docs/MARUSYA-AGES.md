# Возрастные образы Маруси

Референсы подростка/взрослой предоставлены пользователем 2026-10-04, каждый спереди/сбоку/сзади. Малыш одобрен и сохранен. Это первая упрощенная кубическая адаптация, не точная копия художественной детализации.

| Деталь | Подросток | Взрослая |
|---|---|---|
| Длина корпуса от малыша | 1,35× | 1,8× |
| Пропорции | Голова относительно крупнее, стройный корпус | Корпус длиннее, шире грудь, голова относительно меньше |
| Шерсть | Небольшой воротник, пушистые щеки | Пышный воротник, объемные бока/щеки |
| Лапы | Тонкие | Широкие, массивные |
| Хвост | Умеренно толстый и пушистый | Длиннее и гуще |
| Уши | Небольшие кисточки | Более выраженные кисточки |

Черная шерсть, желтые глаза с вертикальными зрачками и бликами. Графитовые участки близки к черному, а не светло-серому. Возрастные атласы marusya_teen.png / marusya_adult.png имеют 256×256 пикселей, по 16 плиткам 64×64. Детерминированная мелкая фактура шерсти из tools/generate_age_textures.py, без новых игровых библиотек.

Куб body имеет длину 6 / 8,1 / 10,8 модельных единиц по оси Z до внешнего масштаба. Речь о корпусе без головы/воротника/хвоста. Все возраста Маруси рендерятся с масштабом 0,55, изменение пропорций внутри отдельных деревьев. Общая длина всего персонажа растет иначе из-за независимых изменений головы/хвоста. Коробка столкновения Minecraft квадратная в плане, приблизительная, ширина/высота базового EntityType масштабируются 0,55 / 0,7425 / 0,99.

У выросшей Маруси tail состоит из соединенных частей middle/upper/tip. Имя tail сохранено для мурчания/покачивания. При ALERT у выросших моделей наклон 0,25 радиана поднимает хвост, у малыша оставлено прежнее −1,1. Четыре leg0..leg3 с дочерними лапами двигаются прежней походкой; ear0/ear1 с дочерними кисточками участвуют в тревоге. Воротник фиксирован к корпусу, щеки и глаза — к голове.

![Проекции](MARUSYA-AGES-PREVIEW.png)

Повторить: Gradle verifyModels, затем `python tools/preview_age_models.py marusya` (Pillow, numpy, matplotlib). Превью из реальных вершин, общий масштаб всех возрастов. Оно выбирает центральный UV цвет грани, поэтому не показывает всю фактуру/игровой свет и не заменяет приемку Minecraft.

Выбор модели/текстуры идет по прежней синхронизированной стадии. NBT/таймер, владелец/доверие/дом и cooldown поглаживания не меняются. Старые выросшие персонажи сразу получают возрастной вид после обновления. Нужна проверка движения, сна, тревоги, мурчания и отдыха на клиенте/полном BMC4.
