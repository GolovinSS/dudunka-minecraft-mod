# Возрастные образы Дюдюньки

Референсы предоставлены пользователем 2026-10-04: отдельные листы подростка/взрослой, спереди/сбоку/сзади. Малыш сохраняет одобренный прежний вид. Референсы служат художественным ориентиром, это не готовая UV-развертка.

| Деталь | Подросток | Взрослая |
|---|---|---|
| Рост относительно малыша | 1,3× | 1,6× |
| Доля головы | Больше | Меньше |
| Корпус и конечности | Компактнее | Длиннее, плечи шире |
| Рюкзак | Небольшой, почти квадратный | Выше, с боковыми карманами |
| Одежда | Кремовая рубашка, зеленый комбинезон | Та же палитра, больше деталей |

Сохранены очки, пучок с ромашкой, кольцо, подвеска; добавлена ромашка на рюкзаке. Упрощенная кубическая геометрия на ванильных ModelPart, без сторонней библиотеки. Для каждой возрастной модели используются прежние имена анимируемых суставов; кольцо дочернее к правой руке и движется с ней.

Все три дерева Дюдюньки имеют высоту 10,7 модельных единиц до внешнего масштаба. Новые модели нормализуются после построения разных пропорций. Внешний масштаб малыша/подростка/взрослой: 0,55 / 0,715 / 0,88; высота изображения и размеры столкновения растут в соотношении 1 / 1,3 / 1,6. Это небольшой персонаж; коэффициенты не означают рост в полтора блока.

Текстуры подростка/взрослой имеют 256×256 пикселей; материалам отведены 16 плиток по 64×64. Фактура ткани/кожи/волос создается детерминированно tools/generate_age_textures.py (Python, Pillow), у взрослой она немного подробнее. Это технический UV атлас, не раскладка человеческого скина. palette.png не изменен.

Рендерер заранее запекает три дерева, выбирает по e.stage() перед отрисовкой и берет соответствующий atlas. Стадия уже синхронизируется сервером. Данные сохранений не меняются, старые персонажи получают возрастный вид после обновления мода.

Для повторения: Gradle verifyModels экспортирует build/model-preview.json из реальных вершин, затем tools/preview_age_models.py строит проекции (Python, Pillow, numpy, matplotlib). Превью использует центральный UV цвет грани и не показывает всю фактуру/игровой свет. Нужно проверить натуральный вид, очки, тонкие детали, все жесты и позы в Minecraft/BMC4.
