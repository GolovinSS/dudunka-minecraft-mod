# Проверки 0.13.0 alpha — 2026-10-04

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- build/reobfJar, verifyModels и Forge GameTestServer: все 40 обязательных тестов (37 прежних + 3 приветствия).
- Расчет по последовательным секундным наблюдениям: короткий выход и нейтральная зона не дают события; возвращение пешком через нейтральную зону сохраняет уже подтвержденный выход; 10 секунд за границей дают одно возвращение; повторное consume запрещено, минутная пауза и истечение окна работают.
- Пропуск наблюдений/перерыв не создают путешествие; первый отсчет задает исходное присутствие. Низкое доверие и NBT загрузка персонажа не дают приветствие.
- Реальные загруженные ticks Companion: тестовый хозяин выходит на 11 секунд и возвращается. HomeScenes выбирает WAVE раньше цветов, HomeSceneGoal запускает жест и поглощает событие один раз; обычное любопытство не прерывает жест. Shift + пустая рука прерывают сцену, освобождают цель, сохраняют доверие.
- Все девять моделей и 12 активностей проверены verifyModels. Модели/PNG текстур не изменялись.

## Ограничения

- Учет перерывов проверен расчетом наблюдений; реальная выгрузка чанка, дисковый перезапуск и сетевой сеанс двух клиентов новой сцены не запускались.
- В реальной серверной интеграции проверены ticks, жест и команда; графическое отображение, пороговые расстояния в сложном доме, визуальная приемка и полный BMC4 v55.5 требуют игрового теста.
- История выхода/ожидающий жест/пауза временные, не сохраняются. Существующие поля персонажа, дружбы и переноски не менялись. Новых библиотек нет.
