# Проверки 0.19.0 alpha — 2026-10-04

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- Итоговый `build verifyModels runGameTestServer -x downloadAssets --offline`: **75 обязательных тестов прошли**, процесс завершился с exit 0. 66 прежних и 9 новых проверок возврата/переносок. Геометрия девяти моделей / 12 активностей проверена, модели/PNG персонажей не менялись.
- Настоящая выгрузка чанка Незера: сущность и чанк недоступны, запись остается в SavedData; команда через серверную сессию альбома временно загружает последний чанк и возвращает существующий UUID в Overworld. Исходный чанк снова выгружается после снятия transient ticket; persistent forced-chunk флаг отсутствует.
- Штатный перенос живой ожидающей Маруси из Overworld в Nether: прежний UUID доступен в новом уровне, исходный экземпляр отсутствует, режим ожидания и поля исходного дома сохранены. Реальная смена уровня, не только NBT-модель.
- Реестр сериализуется/загружается с владельцем, видом и положением; чужие записи отсутствуют в снимке. Discard удаляет индекс живой сущности. Сетевой snapshot с recovery-данными проходит round-trip; более 32 записей отклоняются.
- Пустой/устаревший индекс: bounded search завершается по таймауту, персонаж не создается заново. Отказ для хозяина в воздухе, чужого владельца и полностью заблокированного места прибытия не переносит сущность.
- Захват Сюси сохраняет полный backup; резервная запись и билет проходят SavedData round-trip. Восстановление выдает новый токен, исходная найденная переноска не выпускает Сюсю. Новая выпускает один раз, сохраняя ожидание и доверие. Изменение Trust в NBT предмета не заменяет серверное значение.
- Действующая переноска в инвентаре блокирует повторную выдачу; чужой игрок и полный инвентарь не меняют билет. При полном инвентаре одна пустая переноска может быть заполнена. Legacy ticket без backup не создает Сюсю.
- Реальный обработчик recovery-команды: чужая сессия, отсутствующий альбом и replay не меняют билет; правильная сессия восстанавливает переноску. Предыдущие команды ожидания/следования, защита переноски, догоняние, домашние сцены, путеводитель, loot и рост прошли.

Первый прогон выявил ошибки новых тестовых фигур (попытка изменять неизменяемый список игроков; обращение к null legacy homeAnchor) и старую геометрию оставшегося GameTest мира. Тесты исправлены, для изменившейся раскладки создан чистый мир. Job теперь держит слабую ссылку на игрока и отменяется при его удалении; длительно удерживаемых Player/Entity нет. Промежуточный полный прогон 73 тестов прошел; после добавления двух отказных проверок итоговый прогон 75 прошел. Ошибка компиляции промежуточного теста из-за совпадения имени переменной lambda исправлена до итоговой сборки.

## Ограничения

- Полный BMC4, реальный клиентский GUI и два сетевых клиента не запускались. Штатные Nether/Overworld переходы и disk entity unload/load выполнены на Forge GameTestServer, без полного модпака.
- Сериализация SavedData проверена; отдельный перезапуск процесса между capture/reissue/release остается ручной приемкой. Не проверены аварийное завершение/откат/повреждение отдельных файлов или удаление измерения сторонним модом.
- Отмена через смену сессии/измерения/удаление игрока и остановку сервера проверена по коду, без отдельной многоклиентской проверки. Закрытие GUI не отменяет уже принятую команду; поздний ответ не открывает экран.
- Старый мир автоматически не сканируется. Неизвестный реестру старый персонаж требует загрузки исходного чанка; старая потерянная переноска без backup невосстановима. Поиск только последнего чанка может завершиться отказом при устаревшей позиции.
- Территориальные моды, реальные лаги и совместимость переноса с прочими модами BMC4 требуют игровой проверки. Автоматического межмирового возврата без команды нет.

Протокол альбома 4: обновить сервер и клиентов. Формат живых персонажей не менялся; добавлен SavedData индекса и необязательный Backup в билете переноски. Предыдущий отчет: VALIDATION-0.18.0.md. Правила: FAMILY-RECOVERY.md; приемка: TESTING.md.
