# Проверки 0.14.0 alpha — 2026-10-04

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- Итоговые build/reobfJar, verifyModels и Forge GameTestServer; все 45 обязательных тестов (40 прежних + 5 альбома).
- Снимок содержит только собственных живых загруженных персонажей в радиусе 64 блоков в текущем измерении; чужие/дальние исключаются. Проверены сохраненные имя, взрослая стадия, доверие, режим и исходное место вылупления.
- Готовый дом со всеми пятью признаками, немедленно отсутствующий торт, удаленный маркер, чужое измерение и незагруженная координата различаются. Проверено отсутствие загрузки домашнего чанка при чтении.
- Пакет точно проходит encode/decode с кириллицей и дружбой. Декодер отвергает более 12 страниц; числовые поля и число друзей ограничены.
- Реальное использование предмета серверным игроком отправляет один ClientboundCustomPayloadPacket только этому игроку, не расходует предмет и не пишет данные в его NBT. Повтор внутри cooldown не отправляет второй снимок. Клик альбомом по своему персонажу также открывает его без изменения доверия/команды. Перехвачены прямые отправки через Connection и через listener; настоящего сетевого клиента нет.
- Большая семья: отображается 12 из 14, на странице не более пяти связей; чтение не сокращает сохраненный реестр дружбы из 13 связей.
- Прежний тест переноски между измерениями теперь ожидает доступность entity lookup в рамках timeout вместо фиксированных 20 ticks после выпуска; производственная логика переноски не менялась.
- Серверный запуск с новым каналом/предметом проходит без загрузки клиентского GUI на стороне сервера. Клиентский экран компилируется; девять моделей/12 активностей проверены verifyModels. Модели/PNG текстур персонажей сохранены.

## Не выполнено

- Графическое открытие/отрисовка экрана, фактическая прокрутка, масштаб GUI, художественная приемка и полный BMC4 v55.5.
- Настоящее сетевое подключение двух клиентов и выделенный сервер. Приватная отправка проверяется в серверном тестовом listener; полный клиентский decode/показ экрана требует игрового сеанса.
- Дисковый перезапуск пользовательского мира и совместимость нового GUI/канала с меню всех модов сборки.

Обычная книга с дружбой в чате сохраняется. Альбом — ограниченный снимок рядом находящейся семьи, не глобальный реестр и не управление персонажами. Сохраняемые поля существующих сущностей/дружбы не менялись; новых библиотек нет. Предыдущий отчет: VALIDATION-0.13.0.md. Правила: FAMILY-ALBUM.md; ручная приемка: TESTING.md.
