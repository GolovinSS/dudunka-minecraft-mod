# Проверки 0.17.0 alpha — 2026-10-04

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- build/reobfJar, verifyModels и Forge GameTestServer: все 60 обязательных тестов (55 прежних + 5 группового домашнего отдыха), BUILD SUCCESSFUL.
- Три своих вида с валидными близкими маркерами получают три отдельные безопасные крытые позиции. Чужой владелец/маркер и исходное место вылупления не включаются.
- Команда ожидания немедленно исключает своего участника; последняя пара продолжает. Удаление домашнего маркера второго участника прекращает оставшуюся одиночную сцену. Уход хозяина отменяет выбор.
- Два прямых HomeTogetherGoal с NoAI и заранее перемещенными на выбранные места участниками проверяют фактическое одновременное сидение: seeded прогресс 1180 тиков заканчивается один раз, подход не дает очко, прерывание не добавляет времени. Для изоляции физики этим двум сущностям временно отключена гравитация; это только тест.
- Отставшая своя Сюся вызывает прежнее приоритетное ожидание; рядом с монстром Маруся выходит из группы. Вода вместо выбранного места отменяет участие.
- Отдельный тест с обычными AI/GoalSelector/навигацией: две Дюдюньки подходят к разным назначенным позициям и действительно сидят в общей сцене на сотом тике. Проверяются реальные позиции и активность, без прямого запуска goal.
- Остальные проверки альбома/команд, дома, роста, переноски, путешествия, дружбы у костра и ошибки яблока прошли. Девять моделей / 12 активностей проходят verifyModels; модели и текстуры не менялись.

## Ограничения

- Полный BMC4 v55.5, графическая приемка, реальная сеть двух клиентов/выделенный сервер и длительное наблюдение не запускались.
- Live AI тест группового отдыха охватывает пару Дюдюнек. Все три вида проверены при выборе мест; реальная ходьба Маруси/Сюси и всех возрастов в новой группе требует ручной проверки.
- Сон/приседание хозяина, вечерняя кровать, поводок/транспорт и приоритет приветствия/сундука/поглаживания в новой группе проверены по коду, не отдельными новыми live тестами.
- Накопление дружбы использует ранее проверенный SavedData/дедупликацию; новый тест заканчивает заранее накопленный прогресс. Полная минута новых сцен и дисковый перезапуск мира в этом прогоне не выполнялись.
- Чанки не загружаются кодом сцены; реальное прерывание выгрузкой/загрузкой в момент отдыха требует ручной проверки. Домашние условия используют существующий кеш до пяти секунд, выбранное место/маркер проверяются сразу.

Новых зависимостей, сохраняемых полей и сетевых сообщений нет. Существующие модели/текстуры/альбом и режимы сохранены. Предыдущий отчет: VALIDATION-0.16.0.md. Правила: HOME-TOGETHER.md; ручная приемка: TESTING.md.
