# Проверки 0.18.0 alpha — 2026-10-04

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- Итоговый build/reobfJar, verifyModels и Forge GameTestServer: все 66 обязательных тестов (60 прежних + 6 поиска/путеводителя), exit 0 после завершения сервера. После уточнения текста Tall House выполнен отдельный build упаковки.
- Точные версии MVS, YUNG’s Better Dungeons и BOP сверены по manifest BMC4 v55.5. Восемь новых таблиц подтверждены JSON и назначением в NBT структур; три biome ID — biome JSON и собственным тегом BOP. Факты/хеши — BMC-EGG-SOURCES.json.
- Реальные зарегистрированные глобальные модификаторы Forge проверены на всех восьми ID с воспроизводимыми разнесенными seed и временным multiplier=10: появляется только назначенный вид. Неподдержанный mvs:empty не получает яйцо; сторонних модов в GameTest окружении нет.
- Старый контейнер моделируется сохраненным NBT обычного сундука с LootTable и без Items: загрузка и настоящее unpackLootTable получают яйцо через текущую ванильную таблицу/GLM. После формирования LootTable исчезает; загрузка и повторная распаковка оставляют NBT/инвентарь одинаковыми. Набор фиксированных seeds и временный multiplier=10 обеспечивают находку для проверки, исходная настройка возвращается.
- Модификатор сохраняет прежний стек алмазов, не добавляет второе яйцо того же вида при повторном применении/наличии импортированного яйца. Multiplier=0 прекращает добавление.
- Выдача одного альбома, сохранение/загрузка реестра по UUID, отказ повторной выдачи после потери и выдача другому игроку. Уже имеющийся во второй руке альбом не дублируется. Полный инвентарь не отмечает успех, после освобождения места выдача выполняется.
- Настоящий обработчик PlayerLoggedInEvent использует world SavedData: первая выдача есть, повторная отсутствует. Шесть страниц имеют содержимое; необязательные места зависят от флагов, флаги проходят сетевой round-trip с пустой семьей.
- Все прежние тесты команд/альбома, дома/дружбы, путешествия, роста, переноски и яблока прошли. Девять моделей / 12 активностей проверены verifyModels; геометрия и PNG персонажей не менялись.

Первый прогон новой проверки GLM использовал подряд идущие малые seeds с похожим первым случайным значением: редкий бросок не сработал ни разу. Исправлен тестовый набор воспроизводимых разнесенных seeds, производственные шансы не повышались из-за теста. Итоговый полный прогон прошел.

## Ограничения

- Полный BMC4, реальный сервер/два клиента, графический экран и измерение редкости не запускались. Чужие JAR только исследованы, не добавлены в нашу сборку или тестовый сервер.
- Проверка старого сундука — NBT-фигура и реальная генерация добычи в GameTest, без запуска пользовательского мира, который был сохранен отдельным процессом до установки мода.
- BOP чанки фактически не генерировались: проверены ID/необязательный тег и прежние тесты природной генерации на ванильных основаниях. Реальная частота в новых биомах остается неизвестной.
- Импорт RS, Loot Integrations и индивидуальная добыча требуют отдельной приемки. Защита от повторного добавления относится к нашему модификатору; чужие моды могут затем менять список.
- Дисковый перезапуск реестра выдачи, настоящий цикл смерти/смены измерения и GUI переходы/прокрутка проверены по устройству SavedData и коду, без новых live клиентских тестов. Сериализация отметки и реальный login обработчик проверены отдельно.

Сохраняемые поля персонажей/семьи не менялись; новый отдельный файл реестра выдачи. Протокол альбома 3 требует обновления сервера/клиентов. Предыдущий отчет: VALIDATION-0.17.0.md. Правила: BMC-EGGS.md / FAMILY-ALBUM.md; ручная приемка: TESTING.md.
