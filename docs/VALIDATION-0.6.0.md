# Проверки 0.6.0 alpha — 2026-10-04

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- Итоговые Gradle build, reobfJar и verifyModels: успешно; предыдущие 11 активностей/модели сохранены.
- Forge GameTestServer: **все 22 обязательных теста прошли**, включая 18 предыдущих проверок.
- Configured feature реально загружается из datapack и вызывается в тестовом ServerLevel: свободное место на мху с водой получает одно яйцо. Оно бесхозное, без угощений и прогресса; повторная попытка не перезаписывает его. Первые листья нормально расходуются и закрепляют владельца.
- Отказ без воды, возле лавы, на камне, в занятом блоке и под низким потолком. Алмазный блок не заменяется. После восстановления безопасных условий трава с водой принимается.
- Поиск колонки ограничен 24 позициями: пол на последней доступной позиции находится, за пределом — нет. naturalEggGeneration=false действительно запрещает размещение, после проверки исходное значение восстановлено.
- Registry wiring: оба placed features декодируются; surface добавлен в swamp/mangrove swamp, cave — в lush caves. Равнины не получают surface; варианты surface/cave не перепутаны.
- JSON-схема forge:add_features проверена по официальному source JAR Forge 47.4.13 (ForgeMod/ForgeBiomeModifiers), а сигнатуры WorldGenLevel/FeaturePlaceContext — по той же зависимости.
- Итог: **BUILD SUCCESSFUL** для `build verifyModels runGameTestServer -x downloadAssets --offline`.

Первый тестовый запуск обнаружил пустой выходной build/resources/main/pack.mcmeta и не загрузил datapack/структуру теста. Исходный pack.mcmeta и метаданные в JAR были корректны. Повторная processResources восстановила выходной файл; затем отдельный GameTest и полный итоговый цикл прошли успешно. Сам Feature не меняет метаданные ресурсов.

## Не выполнено

- Естественная генерация по множеству seed/новых чанков, фактическая частота находок и качество мест размещения; тесты вызывают configured feature напрямую и проверяют подключение к биомам.
- Полный BMC4 v55.5, его дополнительные биомы/генераторы, производительность новой генерации и совместимость порядка features.
- Графическая приемка природного яйца, поиск игроком, обновление реального существующего мира, сетевой сеанс/дисковый перезапуск.
- Интеграция с подтвержденными таблицами структур Better MC; она остается отдельным открытым пунктом.

Новая генерация добавлена Forge biome modifiers без замены ванильных таблиц/features, без retro-generation и без новых библиотек/mixin. Частоту попыток можно менять datapack; биомы других модов автоматически не включены. Персонажи, дома и переноски сохраняют прежний формат. Предыдущий отчет: VALIDATION-0.5.0.md. Ручной список: TESTING.md.
