# Проверки 0.9.0 alpha — 2026-10-04

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- Итоговые Gradle build/reobfJar, verifyModels и runGameTestServer: BUILD SUCCESSFUL. Все 27 обязательных серверных тестов прошли: 26 прежних и один новый.
- Запечены семь деревьев: все три возраста Дюдюньки/Сюси и прежняя Маруся. Все 12 активностей проверены на конечные координаты/углы; анимируемые усики и детали взрослой раковины присутствуют.
- По реальным вершинам ModelPart.render длина Сюси равна 8,8 / 11,44 / 14,96 до масштаба, то есть 1 / 1,3 / 1,7. UV находятся внутри atlas.
- Дополнительная геометрическая проверка: первая секция конуса пересекается с основной раковиной, соседние секции пересекаются друг с другом. Зазор, замеченный в первоначальном превью, исправлен до публикации. Итоговое превью из вершин просмотрено.
- Серверный тест: размеры подростка/взрослой по ширине 1,3×/1,7× от малыша; render scale остается 0,55 без двойного увеличения. Взрослая восстанавливается из полного entity NBT (формат переноски) со стадией, владельцем, доверием и нужной шириной. Это восстановление в памяти, не дисковый перезапуск.
- Сохранены прежняя геометрия всех малышей, palette.png, взрослые модели/текстуры Дюдюньки и Маруся. Две новые PNG декодируются и упакованы в JAR.

## Не выполнено

- Графический Minecraft клиент, визуальное переключение стадий, полная фактура/освещение и художественная приемка по референсам. Превью ортографическое, цвета взяты из центра UV грани.
- Полный BMC4 v55.5, длительная навигация по рельефу/воде, реальные клиентские анимации и сетевой сеанс.
- Дисковый перезапуск с новой взрослой Сюсей в переноске и выпуск на реальном сервере. Прежние серверные тесты переноски/дублирования/межмирового выпуска сохранены и прошли.

Модели — первая упрощенная кубическая игровая адаптация. Отдельные возрастные модели Маруси ждут референсов. Сохранения/таймеры/билет переноски не меняются; новых runtime зависимостей нет. Ручная приемка: TESTING.md; описание/превью: SYUSYA-AGES.md. Предыдущий отчет: VALIDATION-0.8.0.md.
