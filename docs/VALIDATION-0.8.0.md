# Проверки 0.8.0 alpha — 2026-10-04

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- Gradle build/reobfJar и verifyModels успешно; Forge GameTestServer: все 26 обязательных тестов прошли (25 прежних + возрастные размеры Дюдюньки).
- Запечены пять деревьев: Дюдюнька малыш/подросток/взрослая, Маруся, Сюся. Для каждого проверены все 12 активностей, конечные координаты/углы, прикрепление кольца к руке.
- У выросших моделей проверены пучок/ромашка/подвеска; боковые карманы есть только у взрослого рюкзака.
- Реальные вершины всех трех моделей Дюдюньки имеют нормализованную высоту 10,7; UV внутри атласа. Экспорт из ModelPart.render используется для ортографического превью; превью просмотрено.
- Серверный тест проверяет размеры столкновения подростка 1,3× и взрослой 1,6× от малыша, а также восстановление взрослой стадии после NBT чтения.
- Первый тест обнаружил отсутствие начального refreshDimensions у Дюдюньки: getBbHeight малыша оставался базовым размером EntityType. Начальный пересчет после установки kind исправлен, весь набор прошел повторно.
- Прежний блок геометрии малыша и palette.png сохранены; модель/палитра Маруси и Сюси не изменены. Новые текстуры 256×256 декодируются, их генерация воспроизводима.

## Не выполнено

- Запуск графического клиента, визуальный выбор модели рендерером при взрослении, художественная приемка/анимации в Minecraft и полный BMC4 v55.5.
- Сетевой сеанс двух клиентов, реальный перезапуск старого мира. Тест NBT выполняется в памяти.
- Полное соответствие детализации художественных референсов: модели являются первой упрощенной игровой адаптацией.

Сохранения/таймеры/формат сетевых данных не меняются. Новых runtime библиотек нет. Ручная приемка: TESTING.md. Описание/превью: DUDUNKA-AGES.md. Предыдущий отчет: VALIDATION-0.7.0.md.
