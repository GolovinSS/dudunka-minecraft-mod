# Проверки 0.11.0 alpha — 2026-10-04

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- Итоговые build/reobfJar, verifyModels и Forge GameTestServer успешно. Все 32 обязательных теста прошли (28 прежних + 4 дружбы).
- Два репортера, включая обратный порядок UUID, не удваивают одну парную секунду. 59 интервалов дают 1180 ticks и нулевой score; после NBT восстановления первый отсчет не дает offline credit, следующий завершает минуту. Длинный перерыв/явная pause не добавляют пропущенное время; score ограничен 100.
- Владельцы изолированы, связь с самим собой запрещена; вид партнера правильно восстанавливается при любом порядке UUID. Некорректные UUID/виды пропускаются, числовые значения ограничиваются при чтении NBT.
- Интеграция живых server ticks с двумя CampfireRestGoal: персонажи реально сидят у своих мест, завершают предварительно накопленные 59 секунд один раз. Чужой персонаж не получает связь. После вставания хозяина score/progress не растут.
- При score=10 реальные CampfireScenes выбирают разные соседние места с безопасным полом и достижимым путем без огня.
- Книга реально вызывает вывод ClientboundSystemChatPacket с парным score=10 владельцу. Предмет, доверие и команда не меняются. Чужое взаимодействие не отправляет friendship packets и show отвергает чужого зрителя. Это проверка тестового listener без настоящего сетевого клиента.
- Все девять моделей/12 активностей проверены прежним verifyModels; исходники возрастных моделей, геометрия малышей и все PNG текстур сохранены.

## Не выполнено

- Непрерывная реальная игровая минута от нуля в графическом клиенте: серверная интеграция использует предварительно накопленные 59 секунд и затем реальные ticks для завершения минуты; полный расчет времени отдельно проверен ledger тестом.
- Дисковый перезапуск мира, дружба новой версии через реальный межмировой выпуск переноски и сетевой сеанс двух клиентов. Проверка сохранения ledger выполняется через NBT в памяти; прежние тесты переноски/смены измерения прошли.
- Полный BMC4 v55.5, клиентское отображение чата, баланс минут/порогов, фактическая сложная навигация друзей и художественная приемка всех возрастных моделей.

Сохранения персонажей, модели/текстуры и переноска не меняются. Новая дружба хранится отдельным серверным SavedData; без новых библиотек. Предыдущий отчет: VALIDATION-0.10.0.md. Правила/ограничения: FAMILY-FRIENDSHIPS.md; ручная приемка: TESTING.md.
