# Проверки 0.5.0 alpha — 2026-10-04

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- Gradle build, reobfJar, verifyModels: успешно. Три модельных дерева и все 11 активностей проверены без окна.
- Forge GameTestServer: **все 18 обязательных тестов прошли**, включая 14 предыдущих проверок.
- Настоящий ServerPlayer.openMenu запускает Forge-событие: свой персонаж получает запрос, чужая семья, другие виды и ожидающая Дюдюнька его не получают. Проверено достижимое место подхода, запуск цели и сохранность трех алмазов в сундуке.
- Настоящий closeContainer завершает запрос; дополнительные tick после закрытия безопасны. Немедленное повторное открытие не обходит cooldown. Другой игрок уведомляет свою Дюдюньку.
- Составное ChestMenu с CompoundContainer распознает обе части по принадлежности контейнеру; виртуальный SimpleContainer не считается сундуком. Физическая сборка двойного сундука и его анимация остаются ручной приемкой.
- Торт выбирается без случайного условия, получает CAKE_RUN и реальный путь к соседней безопасной позиции. Состояние торта не меняется. Удаление цели останавливает поведение/навигацию, дополнительные tick не вызывают исключение. Режим «жди» блокирует выбор торта.
- Открытый сундук не отменяет WAIT_FOR_SYUSYA. После удаления отставшей Сюси обычная семейная цель уступает запросу сундука; запрос истекает через 5 секунд, даже если меню остается открытым.
- Итог: **BUILD SUCCESSFUL** для `build verifyModels runGameTestServer -x downloadAssets --offline`.

Тестовые персонажи для проверки пути явно установлены на пол (onGround): сразу созданная сущность еще не получила первый физический тик, а наземная навигация до этого не строит путь. Промежуточные два отказа устранены подготовкой теста; производственная проверка достижимости сохранена.

## Не выполнено

- Полный BMC4 v55.5, реальная отмена открытия модами привата, модовые контейнеры, шейдеры.
- Графический клиент: путь на сложной геометрии, вид бега/взгляда, две реальные сетевые сессии.
- Реальное прибытие/поведение на всех ступенях, заборах и мебельных блоках; производительность больших семей.
- Перезапуск настоящего сервера и дисковое сохранение всех механик; текущие сцены/запросы намеренно не сохраняются.

Мод не читает слоты меню и не меняет сундук/торт. Проверки подтверждают серверные события и пути в простой тестовой геометрии, не полную игровую совместимость. Предыдущий отчет: VALIDATION-0.4.0.md. Ручной список: TESTING.md. Дополнительных библиотек, mixin и принудительных билетов чанков не добавлено.
