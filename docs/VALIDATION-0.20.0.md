# Проверки 0.20.0 alpha — 2026-10-04

Minecraft 1.20.1 / Forge 47.4.13 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- Итоговый build, verifyModels и Forge GameTestServer: **84/84 обязательных теста**, exit 0. 75 прежних плюс 9 новых проверок причин отказов, протокола, записок и добычи. Девять возрастных моделей / 12 активностей прошли проверку геометрии. После нормализации лишних завершающих переводов строк импортированных файлов выполнена финальная упаковка JAR; игровая логика от проверенного прогона не менялась.
- Отказы возврата различают неподходящее положение хозяина, поводок/транспорт, заблокированное место, занятый поиск и оставшуюся паузу; прежняя позиция/UUID не меняются. Отмена старой сессией освобождает job и сохраняет cooldown. Прежние тесты настоящей выгрузки/загрузки исходного чанка и переноса между Nether/Overworld проходят.
- Отказы переноски различают действующий предмет во второй руке, полный инвентарь, чужого владельца и legacy ticket без backup. Неуспешные операции сохраняют прежний билет; успешная выдача меняет билет и сообщает CARRIER_RESTORED.
- Настоящий обработчик команды и закодированный серверный пакет проверены на NO_BACKUP: верные сессия/номер запроса, нет ответа другой семье, replay/поддельная сессия не создают новых ответов и не меняют билет. Реальный таймаут команды отправляет NOT_FOUND, завершает поиск и не создает сущность.
- Все 15 серверных кодов, retrySeconds и приватный trailMask проходят сетевой round-trip; слишком большой retry и недопустимый mask отклоняются. Прежние пределы 12 семейных / 32 recovery страниц сохраняются. Протокол 5.
- Реальное use записки 3 до записок 1/2 сохраняет находку без открытия поздних текстов; повторное чтение идемпотентно, предмет не расходуется. Другая семья получает только собственный прогресс даже при передаче предмета. SavedData round-trip сохраняет все три бита, снимок альбома фильтрует их по UUID.
- Десять страниц путеводителя/истории имеют содержимое. Поздние тексты скрыты до непрерывного прогресса, серверный MVS-флаг выбирает верную ветку, отключение trailNotes отражается серверным флагом.
- Зарегистрированные GLM проверены на пяти ванильных деревенских таблицах и подтвержденных mvs:houses_common / mvs:houses_flower. Неподдержанный mvs:empty остается пустым. Независимый бросок записки не расходует случайную последовательность LootContext; повторное применение сохраняет исходные алмазы и не добавляет свою записку повторно. trailNotes=false прекращает добавление.
- JSON ресурсов читаются, все 33 GLM-пути существуют и не дублируются; ru/en имеют одинаковый набор ключей, все коды результата локализованы. Имена предметов и ссылки на штатную текстуру бумаги заданы ресурсами. Модели/PNG персонажей не изменены.

## Среда и промежуточные проверки

Чистый GameTest мир, локальный кэш Forge/Gradle. ForgeGradle сначала пытался скачать MC metadata несмотря на offline; для сервера скопирован уже имеющийся 1.20.1 version.json в build/downloadMCMeta/version.json. Итоговая команда: Gradle 8.8 build verifyModels runGameTestServer -x downloadMCMeta -x downloadAssets --offline. Это локальное использование кэша, настройки проекта/зависимости не изменены.

Первый новый loot-тест слишком часто менял autosave-конфигурацию, вызвав перезагрузки Forge и ложный отказ. Проверка независимого RNG переписана без частых переключений настроек. Тест приватного ответа сначала учитывал пакеты подготовки игроков; списки очищены перед командой. Для меняющейся раскладки использовался чистый тестовый мир. Финальный полный прогон проходит.

## Ограничения

- Полный BMC4, графический экран и два настоящих сетевых клиента не запускались. Причины/сетевые данные проверены на Forge сервере с тестовыми ServerPlayer, без настоящего клиента. Отсчет паузы и перенос длинного текста оценены по коду; проверка окна/масштаба GUI остается ручной.
- Сторонние MVS / Loot Integrations / Repurposed Structures в GameTest окружение не подключены. Проверены зарегистрированные таблицы и выбор ветки по серверному флагу; доступность реальных сундуков, замена добычи модами и итоговая редкость записок требуют игры. Прежние проверенные IDs не расширялись непроверенными структурами.
- SavedData сериализация и чтение проверены. Перезапуск отдельного процесса между чтением записок или capture/reissue/release, смерть/переход реального клиента и моды территорий остаются ручной приемкой. Crash-atomic сохранение разных Minecraft файлов не заявляется.
- История помогает поиску, но не создает/не гарантирует яйцо. EggLootModifier и производственные шансы яиц не менялись. Старые сундуки с уже сформированным Items не пополняются.
