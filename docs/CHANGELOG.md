# Изменения

## 0.2.0 alpha — поведение семьи

- Серверные активности, синхронизированные клиентам: любопытство, ожидание, тревога, отдых, сон, жесты.
- Черновые процедурные idle/run/sit/sleep, поправить очки и помахать; кольцо следует за рукой.
- Индивидуальное поведение персонажей, локальный поиск растений и укрытий, вечернее возвращение.
- Семья ждет Сюсю своего игрока. Дюдюнька расходует по одному лежащему яблоку, не читает сундуки.
- Доверие открывает приветствие Дюдюньки от 25. Новые события достижений.
- Расширены GameTest и проверки моделей/поз.

Совместимость: тот же Forge 47.4.13 / Minecraft 1.20.1 / целевой BMC4 v55.5. Полный игровой запуск модпака и визуальная приемка не выполнены. Обновление мира сохраняет возраст, владельца, дом, кормление и доверие. Устанавливать только один JAR Dudunka Family, старый 0.1.0 убрать из mods.
