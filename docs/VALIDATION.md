# Проверки 0.16.0 alpha — 2026-10-04

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- Итоговые build/reobfJar, verifyModels, Forge GameTestServer: все 55 обязательных тестов (50 прежних и 5 для команд альбома), BUILD SUCCESSFUL.
- Явные команды ожидания и следования: авторитетный ответ с UUID/режимом, освобождение домашней сцены, сохранение режима через существующий NBT, сохранение доверия, стадии и дома. Альбом во второй руке работает; открытие не блокирует первую команду своим cooldown.
- Отказ чужому владельцу, без предмета, при удалении за 64 блока, spectator, непоказанному 13-му персонажу и удаленной сущности. Ответ удаляет недоступную страницу.
- Повтор пакета/номера запроса, частый запрос, сессия предыдущего открытия и отсутствие авторизованного отправителя не исполняются. Повторная явная команда «ждать» не переключает режим.
- Команда с UUID/сессией/номером/режимом проходит codec round-trip. Прямой серверный обработчик отправляет custom payload только отправителю; чужое соединение не получает ответ.
- Проверки прежнего альбома, путешествий, домашних сцен, дружбы, роста, переноски и ошибки яблока сохранены. Девять моделей / 12 активностей проходят verifyModels; геометрия и PNG персонажей не изменены.
- Клиентский экран компилируется; выбор UUID/прокрутка сохраняются после ответа, листание/команды блокируются до ответа или таймаута. Поздний ответ применяется только к текущему экрану с соответствующими сессией и запросом.

Первый полный прогон выявил старую возрастную тестовую фикстуру, где игрок не размещался рядом с Марусей: исправлено для новой общей проверки расстояния. Один тест сидящего отдыха у костра в первом прогоне также не прошел; добавлена диагностика позиций/состояний, в итоговом полном прогоне он прошел. Причина этого единичного сбоя не установлена; исправление логики костра не заявляется.

## Ограничения

- Полный BMC4 v55.5, графический клиент, реальный сеанс двух клиентов/выделенный сервер и искусственная задержка сети не запускались.
- GUI, обработка позднего ответа/закрытия и минутное истечение сессии проверены по коду, без отдельного автоматического клиентского теста. Приватный ответ проверен перехватом серверных пакетов, без сетевого соединения.
- Команды проверены с загруженными сущностями; реальную выгрузку чанка в момент нажатия и дисковый перезапуск пользовательского мира следует проверить вручную. Серверный поиск UUID не загружает чанки.
- Команда «следовать» возвращает обычный выбор AI: семейные приоритеты, самостоятельные интервалы Маруси, поводок и транспорт действуют.

Новых библиотек и сохраняемых полей нет. Протокол альбома 2 требует одинаковой версии клиента и сервера. Предыдущий отчет: VALIDATION-0.15.0.md. Правила: FAMILY-ALBUM.md; ручная приемка: TESTING.md.
