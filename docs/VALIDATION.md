# Проверки 0.10.0 alpha — 2026-10-04

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Цель: Better MC BMC4 v55.5.

## Выполнено

- Итоговый `build verifyModels runGameTestServer -x downloadAssets --offline`: BUILD SUCCESSFUL; reobfJar выполнен. Все 28 обязательных серверных тестов прошли (27 прежних + взросление/поглаживание Маруси).
- Все девять деревьев персонажей запечены, для каждого проверены все 12 активностей на конечные координаты/углы. Сохранены анимируемые head/tail/ear0/ear1/leg0..leg3, кольцо и усики других персонажей.
- Длина cube body Маруси равна 6 / 8,1 / 10,8 модельных единиц, то есть 1 / 1,35 / 1,8. Проверены дочерние кисточки/лапы; соседние секции выросшего хвоста пересекаются, геометрических зазоров нет.
- Ортографическое превью экспортировано из настоящего ModelPart.render и просмотрено: разные головы, корпус, воротник, лапы и хвост по возрастам. Превью не показывает полную фактуру.
- Серверный тест подтверждает ширину подростка 1,35× и взрослой 1,8× от малыша, фиксированный render scale 0,55. Взрослая принимает поглаживание (+2 доверия, cooldown 600 ticks), после NBT чтения остаются стадия/доверие/ширина; Shift-взаимодействие включает «жди».
- Геометрия всех малышей и palette.png сохранены; возрастные модели/текстуры Дюдюньки и Сюси не меняются. Новые атласы Маруси декодируются и находятся в JAR.

## Не выполнено

- Графический клиент, визуальное переключение возрастов, художественное сходство по референсам, фактура/освещение и реальные движения лап/хвоста/кисточек. verifyModels проверяет числовые преобразования, не красоту позы.
- Полный BMC4 v55.5, графическая приемка сна/мурчания/мебели/костра, длительная навигация и реальная сеть двух клиентов.
- Дисковый перезапуск старого мира; серверный NBT тест выполняется в памяти.

Отдельные возрастные модели всех трех персонажей теперь реализованы в первой упрощенной адаптации; художественная приемка остается открытой. Таймеры/формат NBT/сеть не меняются, новых runtime зависимостей нет. Предыдущий отчет: VALIDATION-0.9.0.md; описание/превью: MARUSYA-AGES.md; ручная приемка: TESTING.md.
