# Проверки 0.4.0 alpha — 2026-10-03

Forge 47.4.13 / Minecraft 1.20.1 / Java 17. Целевой модпак: Better MC BMC4 v55.5.

## Выполнено

- Gradle build, reobfJar, verifyModels: успешно. Три модельных дерева и все десять активностей проверены без графического окна.
- Forge GameTestServer: **все 14 обязательных тестов прошли**. Сохранены 11 тестов 0.3.1, включая защиту от повторного тика после яблока.
- Поглаживание Маруси: чужой игрок не добавляет доверие; пустая рука хозяина добавляет 2; повторный ПКМ во время cooldown не добавляет доверие. PetCooldown переживает NBT-сериализацию; восстановление не обходится повторным ПКМ.
- Shift + ПКМ переключает ожидание во время cooldown. Поглаживание ожидающей Маруси сохраняет режим; доверие ограничено 100.
- Реальные серверные тики: к 10-му тику активна PURR, к 50-му сцена окончена, но cooldown действует; на 610-м повторное поглаживание снова добавляет доверие.
- Сюся: при нулевом доверии атрибут скорости 0,08; кормление сразу дает доверие 5 и значение 0,082.
- Сохраненный сторонний модификатор и измененная базовая скорость сохраняются. Пять повторных NBT-загрузок при доверии 100 не накапливают бонус; доверие 0 удаляет только модификатор семьи; завышенное доверие ограничено 100. Маруся не получает бонус Сюси.
- После выпуска из переноски Сюся с доверием 45 имеет значение скорости 0,098 — бонус восстановлен один раз.
- Итог: **BUILD SUCCESSFUL** для `build verifyModels runGameTestServer -x downloadAssets --offline`.

## Ограничения проверки

- Графический клиент: звук, частицы, вид новой позы и синхронизация с двумя настоящими клиентами еще требуют приемки.
- Полный BMC4 v55.5, его эффекты скорости, шейдеры и поведение на сложном рельефе не проверены запуском.
- Диск/перезапуск настоящего сервера и сохранение при выгрузке чанка проверяются вручную; автотесты используют NBT-сериализацию и игровые тики.
- Баланс прироста доверия и скорости пока предварительный. Значения атрибута не являются измерением блоков в секунду.

Версия 0.3.1 остается в dist для текущей игровой проверки. Предыдущие отчеты: VALIDATION-0.3.1.md и более ранние. Ручная приемка: TESTING.md. Дополнительных библиотек и mixin не добавлено.
